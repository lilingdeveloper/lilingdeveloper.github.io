WebMonitor 技术支持与使用说明

适用于 iOS / iPadOS 版本 WebMonitor

一、功能简介

WebMonitor 是一款在设备本地运行的网页数值监控与定期提醒工具。你可以添加需要关注的网页，指定页面上的特定文本或数值区域，由应用在本地加载页面、提取当前数值并在满足条件时发送本地通知。

二、基本使用方法

  1. 添加监控卡片：在看板页点击右上角添加按钮，输入目标网页地址并加载页面，点选页面中需要跟踪的数值或文本元素后保存。
  2. 配置登录凭据与步骤（可选）：若目标页面需要登录，可在「设置 → 密码管理」中将账号密码保存在系统钥匙串（Keychain）中，或在卡片详情页的「登录步骤 / 取数步骤」中查看、调整或重新录制操作步骤。
  3. 刷新与人工接管：在看板页下拉或点击卡片刷新即可执行检查。当网页出现图形验证码、短信验证或页面结构变更需要人工处理时，卡片会暂停自动步骤并提示展开实时网页浮层，供你直接在页面上完成验证。

三、常见问题（FAQ）

  • 为什么卡片提示需要手动操作？
    当目标网站弹出验证码、二次验证或页面布局发生变化导致本地规则无法继续自动执行时，应用会暂停自动操作并保留当前页面状态，你可以展开实时网页窗口手动完成验证。
  • 保存的网站账号密码存储在哪里？
    账号密码与网页会话 Cookie 仅加密存储在你设备的 iOS 系统钥匙串（Keychain）中，不会上传至开发者或任何第三方服务器。
  • 如何删除已保存的数据或已上传的诊断信息？
    你可以在「设置 → 密码管理」中删除单条凭据；在「设置 → 日志与诊断」中关闭轨迹上传或点击「删除已上传的数据」清除服务端记录；卸载应用将移除本地沙盒中的全部卡片配置。

WebMonitor Technical Support

For WebMonitor on iOS & iPadOS

1. Overview

WebMonitor is an on-device utility for tracking specific text or numeric values on webpages and scheduling local reminders. It loads user-configured webpages directly on your device, extracts the selected page elements, and sends local notifications when values change or thresholds are met.

2. Basic Usage

  1. Add a Monitoring Card: Tap the add button on the dashboard, enter the target webpage URL, select the text or number element you want to track on the loaded page, and save.
  2. Configure Credentials & Steps (Optional): For pages that require sign-in, you can store credentials in the iOS System Keychain via Settings → Password Manager, or inspect, edit, and re-record login and extraction steps in the Card Detail view.
  3. Refresh & Manual Verification: Trigger a check from the dashboard. If a website presents a CAPTCHA, two-factor prompt, or layout change that requires manual input, the App pauses automatic execution and lets you open the live webpage overlay to complete verification directly.

3. Frequently Asked Questions

  • Why does a card ask for manual interaction?
    When a target webpage displays a CAPTCHA, verification code prompt, or significant layout change, automatic execution pauses so you can complete the interaction directly in the live webpage overlay.
  • Where are my saved website passwords stored?
    Saved website credentials and session cookies are stored exclusively in the iOS System Keychain on your device and are never transmitted to any developer or third-party server.
  • How do I delete my data?
    You can remove saved credentials in Settings → Password Manager, delete any uploaded step-trace metadata via Settings → Logs & Diagnostics → Delete Uploaded Data, or uninstall the App to remove all local configurations.
